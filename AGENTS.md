## Android SDK Setup for GitHub & Google Jules Agents

This project requires the installed Android SDK for building Android plugins and exporting Godot projects.
Since GitHub Actions and Google Jules environments are recreated from scratch with each run, it is necessary to install the SDK with every agent launch.
